# Native iPhone workflow

Open `ios/ReverseCAD.xcodeproj`, shared scheme **ReverseCAD** (`com.sivasaran.reversecad.trial`, iOS 17+), signed with the Sivasaran Babu development team. `ios/project.yml` is the reproducible XcodeGen definition. The app uses the shared `packages/ReverseCADCore` capture and service contracts.

**Missing cubie exterior demo:** the app opens directly to the camera. Tap **Start scan** and slowly move the phone or rotate the cube with the gap visible. Eight silent frames are analyzed; the strongest accepted face/gap is shown. Alternatively choose one photo. Enter the measured full cube width, create the model, rotate its STL preview, and export. Connection and last-model access are in the camera menu; manual corners are in the result menu. The model remains an exterior envelope with no hidden connector or fit guarantee. Legacy mechanical workflows remain in the source and are accessible with the `-legacyWorkflow` launch argument for integration testing.

1. **Connection:** enter the Mac URL on port 8767 and the contents of the private pairing-token file identified by the startup script. Simulator can use `127.0.0.1`; an iPhone requires the Mac's reachable LAN address. Check connection. The token is stored in Keychain. No model-provider key is stored on the phone.
2. **Project:** create a named repair or explore the clearly labeled synthetic sample. Raw observations remain local until **Process scan**.
3. **Capture:** on supported hardware, start live capture, tap the stationary object, and move the phone around it. The live preview reports accepted/rejected frames, dropped work, view bins, and saved size. Optional motion diagnostics are separate from ARKit's pose. Unsupported hardware offers synthetic replay and import. Review video has no microphone audio. Capture interruptions retain committed observations; reopening recovers them without joining a new coordinate origin.
4. **Evidence:** process the scan with the real paired service. The project screen then shows the blue observed shape. Tap to mark the break or surviving attachment surfaces; all selected break and contact points stay visible as colored markers. Orbit/pan/zoom in the viewport and scroll outside it to move down the page. Caliper measurements and source images are in disclosures. Local patch normals are estimates with uncalibrated uncertainty. Ambiguous or sparse regions need a clearer patch or more observations.
5. **Measurements:** enter critical caliper/ruler dimensions with uncertainty. Values are marked manual and confirmed. Crop bounds and scale reference remain separate from original observations; save and reprocess to apply them. Symmetry requires a selected counterpart, a confirmed plane normal and offset. Symmetry never becomes an observed missing dimension.
6. **Design:** continue down the same guided screen to choose bridge handle, cup handle or bracket. The service suggests evidence-linked candidates with differences, questions and provenance. Cup saddle pads require explicit approval. Manual mode uses typed template parameters; offline intent fixtures are labeled; live AI mode sends selected images and evidence to the configured provider only when chosen. Advanced parameters and provider settings are in a disclosure.
7. **Results:** after generation the project shows the blue observed scan with the orange proposed part. Review actual CAD/export, contact, collision, assembly, thickness and print checks. Acknowledged prototype export may retain unresolved physical fit. Native sharing uses checksum-verified files from an immutable revision. Each downloaded artifact is reverified before export.
8. **Physical trial:** print coupons first and record the actual revision's printer/settings, measured fit, finishing and iteration count. New geometry starts with **Not tested**; prior revision notes are retained. Keep trial photos with the worksheet described in `PHONE_TEST_PLAN.md`.

**Export scan package** shares a portable ZIP of the original observations and the current `annotations.json` separately, preserving the original capture hashes. Unpack the ZIP on the Mac to import the scan folder. Preserve its companion annotations when reproducing a repair.

Network failures preserve raw captures and pending jobs. Retry sends missing assets only; a saved request ID prevents duplicated repair revisions after a lost response. Use **Resume saved job** after relaunch. Cancel stops the active job without deleting saved observations. Project deletion has explicit local-only or local-and-server choices.

Automated Simulator, native buffer/video tests and unsigned device builds establish software behavior only. They do not establish live LiDAR/VIO performance, physical dimensions, printed fit or strength. Actual run evidence and current pass/fail status are in `reports/` and the main test report.

# Requirements and validation status

This audit maps the mandatory scope in [REVERSE_CAD_SPEC.md](../REVERSE_CAD_SPEC.md), [CODEX_BUILD_PROMPT.md](../CODEX_BUILD_PROMPT.md), and [PHONE_TEST_PLAN.md](../PHONE_TEST_PLAN.md) to implementation and retained evidence. It is a software audit, not a phone calibration or printed-fit report. The authoritative execution details belong in [TEST_REPORT.md](../reports/TEST_REPORT.md).

Status meanings:

- **Automated evidence**: a retained completed run exercises the capability. This does not imply every possible input or the latest untested edit passed.
- **Implemented; source-reviewed**: the control/path exists, but it was not separately exercised by a dedicated interaction test. This is distinguished from the tested shared workflow.
- **Physical trial required**: cannot be established by software replay, Simulator, or CAD validity.
- **Explicitly limited**: supported behavior is bounded and the application must ask for evidence outside that scope.
